Embeddings learn similarity from nothing but next-token

A tiny model is trained on one objective only: given the current token, predict the next token in a toy grammar. It is never told that cat and dog are related. Yet because same-category words share the same next-token distributions, the learned embedding table clusters them on its own. Colours below are only for us to check — the model never saw them.

The toy grammar (all the model ever sees)

animals = cat, dog, cow  ·  fruits = apple, mango  ·  verbs = eat, chase, see
Sentences follow templates like
<animal> <verb> <animal> and <animal> <verb> <fruit>, chained together. So every animal is followed by the same set of verbs, every verb by the same mix of animals/fruits, etc. — same category ⇒ same next-token distribution.

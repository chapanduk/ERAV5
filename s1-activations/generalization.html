Memorization vs generalization — and data closes the gap

The same over-parameterized network is trained on the same noisy task at three dataset sizes. On tiny data it memorizes — train loss crashes to ~0 while held-out loss stays high (a huge gap). As the dataset grows it can no longer memorize, so it learns the true boundary instead, and train/test converge. More data is what closes the gap. Data is everything.

Generalization gap vs dataset size

What you're seeing

N = 20: the net has thousands of weights for 20 points — it threads the boundary through every point, including the flipped/noisy ones. Train loss → 0, but the boundary is nonsense off the training points, so test loss explodes. That's pure memorization.

N = 2000: now there are far more points than the net can memorize, so the only way to lower the loss is to actually recover the true boundary. Train and test loss meet near the noise floor — the irreducible error from flipped labels.

The bar chart is the proof: the train↔test gap shrinks monotonically as N grows.

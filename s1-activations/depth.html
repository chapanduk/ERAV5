Depth without nonlinearity is a lie

Five stacked linear layers collapse into a single linear map, so a 5-layer linear net is no stronger than 1 layer — both draw a straight line and fail the ring identically. Insert a ReLU between the same five layers and it suddenly solves it. The proof at the bottom multiplies the five weight matrices numerically and shows the product is one matrix.

Bonus proof — the five weight matrices multiply into one

Panel (b) with no activation computes z = x · W₁ · W₂ · W₃ · W₄ · W₅ + beff. Matrix multiplication is associative, so that whole chain is a single 2×1 matrix.

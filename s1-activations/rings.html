Activations exist for a reason

Two concentric noisy rings (inner = class 0, outer = class 1) are not linearly separable. Both models train on the same data with the same loop. Panel (a) is a plain linear model; panel (b) is a deep network — pick 1–3 hidden layers and units per layer, and toggle the activation. With ReLU on, the stacked layers bend the boundary into a ring; switch the activation off and no matter how many layers you stack, it collapses back to a single straight line.

Each hidden layer applies the activation a = max(0, z) (ReLU) or a = z (none). With the activation off, every layer is linear — and any stack of linear maps is still just one linear map, so even a 3-layer network collapses to a straight line. With ReLU on, each layer can bend, and stacking layers composes bends into a closed ring. Depth and width give you more bends; the activation is what makes bending possible at all.
